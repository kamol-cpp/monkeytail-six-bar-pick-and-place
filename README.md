# MonkeyTail — Six-Bar Pick-and-Place

**Status:** Completed · February–May 2026  
**Area:** Mechanisms, mechatronics

An adjustable six-bar robot for automated pick-and-place motion.

## Engineering work

- Modeled three six-bar configurations in MATLAB and compared workspace and mechanical advantage.
- Performed inverse dynamic force analysis to size the actuator for a calculated 0.258 N·m peak motor torque at 20 rpm with a 100 g payload.
- Designed the SolidWorks assembly and mirrored four-bar servo gripper, then fabricated and integrated the robot.
